## ⚙️ How It Works

- Password input is hidden by default
- Clicking the checkbox reveals the password
- Clicking again hides it
- JavaScript changes the input type dynamically

```javascript
if(password.type === "password"){
    password.type = "text";
}else{
    password.type = "password";
}
```
